
# Pune Walk-In Drive & Hiring Management Platform

A centralized platform for managing walk-in recruitment drives,
candidate applications, interview queues, evaluations and hiring outcomes.

## Technology Stack

- Frontend: React, Vite, Tailwind CSS
- Backend: Java 21, Spring Boot
- Database: MySQL

## Project Structure

- `frontend/` — React application
- `backend/` — Spring Boot API
- `database/` — SQL scripts
- `docs/` — Project documentation

## Frontend Setup

```bash
cd frontend
npm install
npm run dev
```
